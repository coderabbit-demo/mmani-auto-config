# Product

## Register

product

## Users

Repository maintainers setting up an initial CodeRabbit configuration on desktop or mobile, including people who do not know the YAML settings.

## Product Purpose

Ask pointed questions and produce a schema-validated `.coderabbit.yaml` for the user to review and commit. Run entirely in the browser and support simple static self-hosting.

## Brand Personality

Concise, constructive, specific: follow the official CodeRabbit brand guidelines: orange, mauve neutrals, Geist and Hack, supplied intact logotype, with clear community-project attribution.

## Anti-references

Avoid generic rules inserted without user intent, credential onboarding, and claims that local validation establishes remote repository access or review behavior.

## Design Principles

- Keep path instructions, guideline documents, and linked repository context distinct.
- Explain the effect of each choice with concrete examples.
- Preserve unfinished work; make errors actionable at their fields.
- Make the preview and export identical and accurately state what was validated.
- Keep generation local with no account, tokens, or AI API keys.

## Accessibility & Inclusion

Support keyboard navigation, visible focus, descriptive field errors, readable contrast, reduced motion, and narrow mobile layouts. These are verified behaviors, not a claim of full WCAG conformance.
